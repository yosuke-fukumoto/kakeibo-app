# 家計簿アプリ

ブラウザだけで動くシンプルな家計簿Webアプリです。HTML / CSS / JavaScriptのみで作られており、サーバーやデータベースは使用していません。

## できること

- 収入・支出の記録（日付・カテゴリ・金額・メモ）
- **固定費の自動計上**：家賃やローンなど毎月（または毎週・毎日）発生する支払いを一度登録しておくと、アプリを開くたびに自動でその月までの記録が計上されます
  - 頻度は「毎月」「毎週」「毎日」から選択可能
- カレンダー表示：日付ごとの収支をひと目で確認でき、日付をクリックするとその日の記録を追加・絞り込み表示できます
- 月ごとの収支サマリー（収入・支出・差引）

## データの保存について

記録したデータは、ブラウザの`localStorage`に保存されます。

- サーバーには一切送信されません
- 保存されたデータは、**そのブラウザ・その端末だけ**で見ることができます（別の端末やブラウザからは見えません）
- ブラウザのデータ（キャッシュやサイトデータ）を削除すると、記録も消えてしまうのでご注意ください

## 使い方

1. `index.html`をブラウザで開く（またはGitHub Pagesなどで公開したURLにアクセスする）
2. 「記録する」フォームから収入・支出を入力
3. 毎月（毎週・毎日）決まって発生する支払いは「固定費を管理する」から登録しておくと、次回以降は自動で計上されます

## 技術構成

- HTML / CSS / JavaScript（フレームワーク不使用）
- 外部ライブラリ：Google Fonts（Shippori Mincho / Zen Kaku Gothic New）のみ
- データ保存：ブラウザの`localStorage`

## 開発の背景

アプリ開発の学習と、既存の家計簿アプリにあった不満を解消する目的で開発しました。
